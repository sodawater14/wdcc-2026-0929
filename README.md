# WDCC 2026 · 9.29 同济大学会议图文记录

**[总览 →](https://sodawater14.github.io/wdcc-2026-0929/five-days/)**

**[在线体验 →](https://sodawater14.github.io/wdcc-2026-0929/)**

Su Runxiang 整理的 WDCC 2026 年 9 月 29 日会议记录：15 份报告、390 张现场照片，结合录音修复转录、原始录音与个人总结，呈现可交互的桌面端图文档案。

## 浏览方式

- 点击首页任一报告封面，展开图片浏览界面；Back 或 Esc 返回首页。
- 在大图上滚动、拖动，或按左右方向键切换图片，支持首尾循环。
- 点击“AI转录修复版 × 个人总结”展开独立滚动双栏，右侧保留核心观点、要点、研究思路与经验、关键词。
- 再次点击选中的入口即可收起。弧形滑块可拖动，也支持键盘操作。
- 面向电脑端浏览；“分享你的看法吧”提供信纸输入、草稿自动保存与投稿。当前默认本地提交标记为测试，不上传 GitHub；本地网址添加 `?feedback=remote` 可验收真实云端提交。

## 本地预览

在本目录打开终端，运行 `node server.mjs`，然后访问 http://127.0.0.1:4187 。也可双击 `启动预览.cmd`。

T01–T15 全部开放，共 15 份完整报告、390 张图片。大图区域内滚轮、拖动、触控板横滑或左右方向键切图；图片区外滚动查看文案。两栏文字独立滚动，两侧留白用于整页滚动。Back 或 Esc 返回首页。

进入报告时文案默认收起，两个入口均为蓝色；点击展开并变红，再次点击收起。报告内切换面板保留阅读位置，重新进入则重置。首页编号在鼠标进入、离开时逐字符上下跳动；系统开启减少动态效果时不跳动。

全部 15 份报告的转录与个人总结双栏均使用弧形滚动条：文字框填满入口栏下方的可用高度，底部留 24px；左侧蓝色 50px 圆角，右侧红色 20px 圆角。支持滚轮、拖动滑块以及聚焦滑块后使用方向键、PageUp/PageDown、Home/End。内容不足一屏时隐藏对应滑块。效果参考：https://codepen.io/cbolson/pen/vELrOPz ，组件采用原生滚动与 SVG 路径重新实现。

## 内容与技术

页面使用静态 HTML、CSS、JavaScript、GSAP 与 SVG，浏览页面无需构建步骤；匿名投稿使用独立的 Workers/D1 后端。站点图片使用 WebP，按浏览需要加载。

网页运行所需的文案与图片均已包含在 `data/`、`assets/` 中，可直接本地运行或部署。`scripts/build_content.py` 用于从作者本地原始资料重新生成静态 JSON 与 WebP，支持上级目录中的 `9.29网站内容文档` 或 `9.29/9.29网站内容文档`，需原始资料和 Pillow；现有网页运行无需执行该脚本。

本地新版使用 2026-10-18 录音修复稿替换原转录，右栏展示个人总结四节；原 AI 总结已移除。修复稿属于发言整理稿，自动识别及校订仍可能存在误差。

录音按需播放：左框灰色圆钮播放后变红，再次点击暂停续播；收起文案继续播放，分享或返回首页会停止并重置。原始 M4A 位于 `assets/audio/`。重新生成需要上级目录修复版 Markdown 及原录音目录。

本次版本包含录音修复文案、15 份原始录音、可拖动进度环、折叠个人总结，以及匿名私有投稿。

## 录音进度环

全部 15 份报告的播放按钮外侧都有蓝色进度环。悬停或键盘聚焦可查看当前位置与总时长，点击或拖动圆环可定位；拖动时暂停，松开后恢复原来的播放状态。左右键调整 5 秒，Home/End 跳到首尾。元数据只在展开当前报告双栏后按需加载，不自动播放；分享、关闭或换报告时归零并取消拖动。线上与本地均支持此功能。

## 个人总结折叠阅读

核心观点和关键词常显；中间两个主题的分点默认全部收起，可同时展开多项。点击标题、Enter 或空格展开说明；同次打开报告时保留状态，重新进入后恢复收起。T12 三项设计能力及 T15 人机分工阶段保留父子关系。所有正文保持红色，关键词按原顺序自动换行。

`node scripts/summary_check.mjs` 检查全部报告、完整文案、分组、状态、键盘和两种桌面尺寸。`scripts/validate_content.py` 另核验 166 个原列表项及全部文案、录音和图片均完整保留。

## 图片与录音加载优化

网页使用专用媒体副本：15 份录音由约 293 MB 降至 152 MB，并将音频索引移到文件开头；详情图由约 128 MB 降至 67 MB，另有约 8 MB 的小预览。原始文件继续保留。当前照片先显示预览，再加载清晰图，相邻照片仅加载小预览，避免同时争用带宽。

媒体同时保存在 GitHub Pages 与独立 Cloudflare 静态资源服务。页面以小资源实测选择先响应的线路，图片慢请求和录音初始化失败可回退另一线路；不同地区的实际速度仍取决于网络。`media-config.json` 配置辅助线路。`scripts/optimize_media.py` 生成带内容指纹的副本与清单，内容重新生成时沿用清单。Cloudflare 部署先运行 `scripts/stage_media.py`，再使用 `media/wrangler.jsonc`，只上传公开媒体。

## 图片放大

点击详情中央照片可放大到窗口内，再次点击图片或右上角“还原”返回；Esc 也可还原。放大期间录音继续播放，不重置时间。原有拖动、滚轮及方向键切图保持原行为；聚焦图片区后 Enter 或空格也可放大。`node scripts/image_zoom_check.mjs` 检查图片开关、原有切图及持续播放。

## 品味滚动阅读

首页底部“品味”箭头进入独立的 `#taste` 视图；滚到底不会自动进入。五段中文文案依次对应 Codrops OnScrollTextHighlight 的效果 3、5、6、7、9，使用本地 GSAP/ScrollTrigger，不接管原生滚动。浅灰底、黑色正文，关键词随进入视口高亮；减少动态效果或动效脚本不可用时保留完整静态文字。

9.29 页面隐藏浏览器最外侧滚动条，仍支持原生滚轮、触控板和键盘滚动；报告框内弧形滚动条保留。品味页进入过渡期间先显示黑色关键词，进入阅读区域并停留约 0.6 秒后再播放重点浮现，离开区域会取消尚未开始的动画。

顶部“返回报告”和浏览器后退恢复首页位置，直接打开或刷新 `#taste` 也可阅读。底部“微出行”在新标签页打开曹鸣报告网站。`node scripts/taste_check.mjs` 检查导航、重复进入、动效与清理、长中文换行、失败降级及两种桌面尺寸。参考项目 MIT 许可见 `vendor/OnScrollTextHighlight-LICENSE.txt`。问答中的 taste 为亮红色，最后一段重点文字为亮紫色。

## 会议封面

每次打开或刷新 9.29 首页时，会议照片保持原比例铺满窗口，居中裁切以突出报告展陈，不显示滚动说明。滚动约 1.5 屏，以 30 组横向百叶 SVG 遮罩露出真实报告首页，完成前可向上滚动撤回。转场完成后移除封面及滚动占位，从报告详情或品味页返回时不重播，重新打开或刷新首页则重新显示；直接访问 `#taste` 跳过封面。键盘聚焦可使用“跳过封面”，减少动态效果时滚动触发短淡出。照片、依赖或初始化失败时开放首页，不阻塞报告阅读。
