# WDCC 2026 · 9.29 同济大学会议图文记录

**[在线体验 →](https://sodawater14.github.io/wdcc-2026-0929/)**

Su Runxiang 整理的 WDCC 2026 年 9 月 29 日会议记录：15 份报告、390 张现场照片，结合 AI 转录原文、AI 总结与综合提炼总结，呈现可交互的桌面端图文档案。

## 浏览方式

- 点击首页任一报告封面，展开图片浏览界面；Back 或 Esc 返回首页。
- 在大图上滚动、拖动，或按左右方向键切换图片，支持首尾循环。
- 点击“AI转录原文 × AI总结”展开独立滚动双栏；点击“个人总结”查看核心观点、要点、研究思路与经验、关键词。
- 再次点击选中的入口即可收起。弧形滑块可拖动，也支持键盘操作。
- 面向电脑端浏览；“分享你的看法吧”为后续功能预留面板。

## 本地预览

在本目录打开终端，运行 `node server.mjs`，然后访问 http://127.0.0.1:4187 。也可双击 `启动预览.cmd`。

T01–T15 全部开放，共 15 份完整报告、390 张图片。大图区域内滚轮、拖动、触控板横滑或左右方向键切图；图片区外滚动查看文案。两栏文字独立滚动，两侧留白用于整页滚动。Back 或 Esc 返回首页。

进入报告时文案默认收起，三个入口均为蓝色；点击展开并变红，再次点击收起。报告内切换面板保留阅读位置，重新进入则重置。首页编号在鼠标进入、离开时逐字符上下跳动；系统开启减少动态效果时不跳动。

全部 15 份报告的 AI 双栏均使用弧形滚动条：文字框填满入口栏下方的可用高度，底部留 24px；左侧蓝色 50px 圆角，右侧红色 20px 圆角。支持滚轮、拖动滑块以及聚焦滑块后使用方向键、PageUp/PageDown、Home/End。内容不足一屏时隐藏对应滑块。效果参考：https://codepen.io/cbolson/pen/vELrOPz ，组件采用原生滚动与 SVG 路径重新实现。

## 内容与技术

页面使用静态 HTML、CSS、JavaScript、GSAP 与 SVG，无需后台服务或构建步骤。站点图片使用 WebP，按浏览需要加载。

网页运行所需的文案与图片均已包含在 `data/`、`assets/` 中，可直接本地运行或部署。`scripts/build_content.py` 用于从作者本地原始资料重新生成静态 JSON 与 WebP，支持上级目录中的 `9.29网站内容文档` 或 `9.29/9.29网站内容文档`，需原始资料和 Pillow；现有网页运行无需执行该脚本。

文案保留原 AI 转写和总结，未进行音频校订。
